# 豌豆 AI 工具 v2.0.6

本次更新基于 v2.0.5 桌面正式版，改进节点画布的保存、交互和 IP 动效。

- 修复远程图片链接失效导致整张画布保存失败、关闭时长时间停在保存中的问题。失效链接会保留并显示提示，节点、连线及已有本地图片继续保存；磁盘写入失败仍会阻止关闭。
- 大图使用后台生成的轻量预览。拖动、缩放期间延后图片切换并暂停无关动画，原图下载、编辑和项目导出保持原始内容。
- 修复大尺寸 GIF、动态 WebP 和 APNG 预览被转换为静态图片的问题。
- IP 改为单一形象的连续循环动效，包括轻微摆动、视线变化和眨眼；后台标签页与拖动缩放期间暂停。

发布前验证覆盖保存与恢复、失效链接、磁盘错误、拖动缩放、IP 动效、图片编辑与导出、动态图片及桌面更新流程。外部付费 API 的在线调用未包含在本次回归中。

本次修复源码与回归测试已同步到 `v2.0.6` 标签。GitHub 下方的 `Source code` 可下载对应源码；直接使用桌面版请下载 `wandou-ai-tools-windows-x64.zip`。

下载 `wandou-ai-tools-windows-x64.zip`，完整解压到独立文件夹后运行 `豌豆AI工具.exe`。更新前请正常保存并关闭旧版。旁边的 `.sha256` 文件用于校验下载完整性。

安装包不包含个人项目、账号或测试数据。已失效的远程图片需重新提供原图才能恢复图片内容。
