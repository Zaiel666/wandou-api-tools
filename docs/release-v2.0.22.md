# 豌豆 AI v2.0.22

2026-11-15 · Windows x64

**本次为手动下载安装发布，暂不设为 Latest、不推送软件内自动更新。** v2.0.16 自带旧更新器实测会删除用户另放在程序根目录的自建文件；“豌豆AI数据”内项目和原图保留，但不能因此认为所有文件都安全。旧用户请先保存并退出，下载本页的 `wandou-ai-tools-setup-2.0.22.exe`，选择原程序目录进行覆盖安装，不使用旧版“立即更新”。

本版包含 v2.0.16 之后的本地修复与绘图功能更新。节点画布侧栏现在可直接创建原生 SVG 生成节点和 GIF 动图生成节点；已有图片的 SVG / AI / EPS 本机转换继续保留。

## 主要变化

- 新增“SVG 矢量”“GIF 动图”侧栏及空白画布双击菜单入口，统一明暗主题、质量与复杂度控件。GIF 可设置帧数与每帧时长，实际输出以渠道返回文件为准。
- 修复模型同步列表缺项时将已选兼容模型或渠道静默切走的问题；修复创建菜单在画布边缘被窗口裁切的问题。
- 完善原生 SVG/GIF 的识别、预览、原件存储、保存重开及自选路径下载；GIF 原件与静态画布预览分开，避免在大量节点中同时播放所有动画。
- 圈画编辑将原图和透明标注分别提交、分别保存；补齐图片生成质量与复杂度选项。
- 完善重复点击、取消、删除、切换项目及保存关闭的任务保护，防止结果进入错误项目；本地尺寸处理失败保留已生成原图，不自动再次调用付费生成。
- 大画布采用按需加载和简化预览，保留原图；支持 1K/2K/4K 输出选择时区分模型原生输出与本地放大，非原生处理有明确标记。

## 安装与更新

新用户可使用安装器 `wandou-ai-tools-setup-2.0.22.exe`，也可解压便携 ZIP 到新的可写目录。现有用户先完成保存并退出，运行安装器安装到原程序目录，并保留“豌豆AI数据”和独立数据目录。不要删除数据目录，也不要在含数据的目录中直接覆盖降级。

已用最终安装器的实际安装核心验证 v2.0.16 覆盖升级：4 个合成数据文件与 2 个自建文件全部保留，311 个新程序文件和 292 个旧程序备份文件哈希匹配。本项未自动点击安装器界面；旧版内置更新器删除自建文件的问题仍存在，因此本次采用安装器下载路径。

自动更新仍使用固定名称的 `wandou-ai-tools-windows-x64.zip`、其 `.sha256` 校验文件及 `update-manifest.json`。安装器与 ZIP 都提供 SHA-256。新包使用 Electron 45.1.0，支持 Windows x64；没有发行者代码签名。

旧版本自动更新由旧版本自带更新器执行。新包的更新器检查不能代替所有历史版本、异常目录或所有机器上的实际升级验证。请确保程序目录和数据目录所在磁盘有足够空间，保存与校验失败时先处理提示后重试。
