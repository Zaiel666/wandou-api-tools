# 豌豆 AI v2.0.35

本版改善节点画布中打开大图和删除图片节点时的响应，并加强撤销恢复过程中的数据保护。

- 静态图片打开大图时，先显示已有预览，再异步切换到原图；图片下载继续使用原件。动图沿用原有播放方式。
- 减少删除节点时重复处理大图片的同步工作，删除记录仍保留原件与恢复所需的信息。
- 撤销或重做正在恢复画布时，暂时阻止编辑和保存半恢复状态；恢复失败时保留原状态以便重试。

撤销历史中图片字符串的新增引用采用约 256 MiB 的保守预算；超过预算时回退到原来的处理方式，因此特别大的项目仍可能出现停顿。响应速度取决于图片、项目和设备。

已有用户请保存并正常退出软件，从本版发布页下载安装器，选择原程序目录升级。已有自选项目目录继续使用原设置。安装器会保留项目、自建文件与旧程序备份；遇到无法识别的冲突时停止，不要删除项目绕过提示。安装器尚无发行者数字签名。

本版手动安装，固定安全自动更新通道仍未开放；公网自动下载、安装和重启的完整链路尚未验收。不要使用存在已知问题的旧版在线更新器。详见 [验证范围](verification-v2.0.35.md)。
