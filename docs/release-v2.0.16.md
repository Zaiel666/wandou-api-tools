# 豌豆 AI v2.0.16

2026-10-27 · Windows x64

本次集中完善图片下载、项目存储和升级保护，画布使用方式保持一致。

画布图片下方的下载按钮、右键下载，以及“资产 → 所有图片”中的下载，都会让你选择保存位置。取消下载不会自动存到其他目录；导出保留原图和透明通道。

首次使用时，节点画布项目、原图与备份默认保存在程序文件夹内的“豌豆AI数据”，软件放在哪个盘，新增项目数据就写入哪个盘。设置显示当前目录和程序内默认目录，可选择“使用程序所在目录”或独立的其他位置。建议将软件放在空间足够且有写入权限的目录。

旧版默认目录在打开编辑页面之前复制并逐文件校验，校验成功才切换；现有自定义目录维持原选择，用户可以显式迁回程序目录。移动整个程序目录后，用同一存储标记识别新位置；只移动程序、遗漏数据或磁盘不可用时，不会创建空白项目库覆盖旧项目。

更新器在存在数据子目录或迁移恢复目录时，只更新程序文件，不遍历、搬动或删除数据。程序替换失败或校验失败会回退。更新包不允许携带项目数据；旧程序备份与更新暂存中若有项目数据，清理时会保留。迁移失败留下的恢复副本也会保留，不再阻断后续正常升级。

更新前需要所有打开的画布保存成功。如果画布保存功能异常未加载，会停止关闭或更新并提示重试，不会跳过保存。

内部原图保持 `.data` 格式，通过软件查看。画布和资产的手动下载继续每次选择保存位置，导出正常图片格式。API配置及工作台浏览器存储仍使用原用户配置位置，不包含在节点项目目录的迁移范围内。旧数据副本保留供回退，不会自动删除。

使用软件内“检查更新”完成正常更新。手动升级前先保存并退出，只替换程序文件，完整保留原目录中的“豌豆AI数据”；更换磁盘时请搬动整个软件文件夹，包含数据目录。不要在含数据的目录里降级覆盖旧程序。

旧版 v2.0.14 / v2.0.15 的正常默认目录和设置中的自定义目录均已测试升级保留。如果曾手动把数据塞进旧版程序目录，或在新数据目录里覆盖运行过旧版，请先备份，采用保留数据目录的手动升级；旧版更新器本身无法通过新安装包提前修复。

从旧版默认目录首次迁移时需要额外的目标磁盘空间，数据较多会延长首次启动时间。空间或写入权限不足会停止迁移并提示处理办法，不会创建空项目库。已有自定义目录继续使用原位置。

建议使用较短的程序路径，例如 `D:\豌豆AI工具`。Windows 更新组件在过深的文件夹中仍可能遇到路径长度限制，导致升级中止并恢复旧程序；不要把软件解压到多层嵌套目录中。

验证覆盖图片显示、下载取消与失败、正常保存退出和重开、旧目录迁移、自定义目录保留、升级失败回退及明暗主题同步。未调用收费生成接口；这些检查不代表所有第三方接口或所有电脑环境都绝对无问题。
