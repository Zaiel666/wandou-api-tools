# 豌豆AI工具 v1.0.88

本版本完善网格海报工作台的构图选择与入口体验，并统一结果节点的快捷操作按钮。

## 更新内容

- 网格海报工作台由 18 套构图扩展到 30 套，新增编辑封面、三联画廊、边注大图、十字分区、电影宽银幕、产品目录等布局。
- 构图选择区从画布底部移动到右侧，采用两列卡片和面板内纵向滚动，中央画布获得更完整的垂直空间。
- 保留“保留手动位置”“变体”“随机生成”等原有功能，30 套构图均可直接选择和应用。
- 首页新增“网格海报设计工作台”卡片入口。
- 节点画布和首页入口统一改为新标签页打开，不再覆盖当前画布或首页。
- 结果节点的下载按钮缩小为与收藏、重新生成按钮一致的 20 × 20 像素规格。
- 下载按钮同步统一边框、图标尺寸、间距、悬停和键盘焦点状态。

## 验证

- 逐一应用并渲染 30 套构图，验证随机生成、变体和手动位置开关。
- 验证草稿保存、PNG 下载、PSD 分层下载与文件签名。
- 验证节点画布和首页入口均打开新标签页且保留原页面。
- 验证结果节点收藏、重新生成、下载三个按钮尺寸和间距一致。
- 验证首页明暗主题、节点画布保存、全屏布局及现有界面回归。
