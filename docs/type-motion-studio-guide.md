入口：`app/homepage-test.html`；文字海报：`app/type-motion.html`。

## 本次范围

- 新版首页三张原创动画 Banner：节点画布、文字动态海报、3D 导演台。
- 每 6.5 秒自动切换，左右切换、圆点选择、暂停；悬停、焦点进入或页面隐藏时暂停；减少动态效果偏好默认不自动播放。
- AI 抠图、去水印、关键词反推、白话转专业语言、视频提示词、图片增强共用 `tool-studio.css`。保留原接口、上传、预览、下载与页面脚本。
- 网格海报另用 `gridform-studio.css` 统一控件；不改海报内容的颜色和字体。支持浅色和暗色切换。
- 思维导图保留此前已有的 neutral 样式，避免通用导航影响其固定头部。

## 文字动态海报

本地 Canvas 2D 原创实现，不复制参考站源码或预设。
30 种原创动效，分类为入场、循环、变形、空间、实验；右侧素材库提供真实绘制缩略图及悬停/聚焦预览。参数、预览画布和素材库采用三栏布局，中小屏自动折行。
主副标题、三种字体、字号、四种比例、三种循环时长、背景/文字/点缀颜色、装饰开关。
草稿本地自动保存；JSON 导入导出；当前帧 PNG；离线播放的独立 HTML；浏览器支持时录制 WebM 或 MP4（按真实 MIME 命名）。
视频导出期间锁定编辑，切到后台或手动取消时丢弃不完整录制并释放流。
此版本没有 GIF 编码、参考站全部预设或自定义字体上传。Banner 是 CSS 循环动画，不是 GIF 文件。

## 导演台入口
