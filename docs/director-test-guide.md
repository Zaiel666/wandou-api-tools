# 3D 导演台（测试画布）

入口：`app/ai-node-canvas-test.html` 左侧创建节点中的 **3D 导演台**。
正式画布未改动。全部 3D 库随应用本地打包，没有运行时 CDN。

## Blender 一步导入（独立桌面测试入口）

双击项目根目录 `start-director-test.cmd`，在同款测试画布中创建/打开 3D 导演台，直接选择 `.blend` 即可。
界面显示“后台转换”，完成后自动导入 GLB，不需要保存中间文件，也不需要另找转换工具。

- 需要本机 Blender（已检测并测试 Blender 4.2 默认安装路径）。源工程 ≤64 MB，转换结果 ≤20 MB。
- 后台进程隐藏运行、禁止工程自动脚本、两分钟超时；停止、关闭导演台、退出测试程序均会取消任务。
- 临时 GLB 读入后清理，原工程不改动。转换失败保留原场景。
- 桌面测试使用 `Wandou-Director-Test` 独立数据目录，不暴露正式 `wandouShell` 接口。
- 与 Codex 浏览器中的测试项目也不共享数据；继续已有项目时，请先用项目合集“导出项目”，再在桌面测试页“导入项目”。API 设置同样独立。
- 浏览器页面本身不能启动 Blender，因此普通浏览器仍显示桌面入口说明，不能宣称刷新浏览器就获得本地执行能力。

已通过真实 Blender 后台转换、取消、源文件哈希不变及临时目录清理测试；渲染端通过自动转换后导入的 DOM 测试。
尚未进行真实 Electron 窗口的文件选择与 GPU 端到端验收。

## 使用顺序

1. 打开导演台，可先用内置汽车熟悉操作。
2. 导入 ≤20 MB 的 GLB（内嵌材质、未压缩）、FBX（内嵌贴图）或 OBJ（灰模）。不支持外置贴图、Draco/KTX2 压缩和动画片段播放。
   Blender `.blend` 推荐使用上述桌面测试入口自动转换；普通浏览器可继续用 `tools/director-blender/convert-blend.cmd` 手动转换后导入。本机 Blender 4.2 已完成实际转换测试。转换器禁用工程脚本、不改原工程、不覆盖已有输出，也不上传文件。复杂程序化材质可能需要手动烘焙；这不是浏览器原生解析 `.blend`。
3. 拖动旋转、右键平移、滚轮推拉。也可使用正面/侧面/俯视/三分之四按钮，以及视口方向键、加减键。
4. 调整主体 X/Z 位置、朝向、镜头视角、灯光和背景。记录起点，换到结束构图，再记录终点。起止点同时记录镜头和主体状态。
5. 播放预演或拖动时间轴。2–15 秒，支持平滑起停或匀速；比例为 16:9 / 9:16 / 1:1。
6. 输出任选：
   - **导出 PNG 静帧**：本地 3D 渲染当前角度，无辅助网格。
   - **静帧 → AI 绘图**：自动建立导演台 → 参考图 → AI 文字绘图。补充提示词后，手动点击生成才调用 API。
   - **生成预演节点**：本地录制视频，添加到画布，可播放或下载。优先 WebM，浏览器只支持 MP4 时用 MP4；扩展名与格式一致，不做伪 MP4。
   - **首尾帧 → AI 视频**：连接两张有序参考图到现有视频节点。它仅使用首尾帧，不保证严格跟随中间运镜；时长仍由现有模型决定，方形参考转为横屏。
7. 保存并关闭：模型数据、起止点、当前视角及缩略图通过测试画布原有持久化保存。未点击保存关闭的编辑不承诺跨刷新恢复。

预演是两个姿态之间的镜头/主体插值，不是完整 3D 软件，也不播放模型内置骨骼动画。
AI 静帧生成可能改变模型细节；它与直接导出的、几何角度确定的 PNG 有区别。

仅记录模型 ID，未记录密钥，未提交收费生成。
