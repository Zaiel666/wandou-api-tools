# 动态海报：以构图承载运动

文字是画面结构，而不是待播放的一段标题。每款海报应在任意帧都具有明确的视觉中心、留白、尺度对比和边界；运动改变结构的张力，不依赖文字从透明到可见的入场效果。

设计库采用字阵、空间、几何、拼贴、编排、实验六类方向，另保留三款先前的海报。33 款使用不同的构图分支，覆盖整块软旗、轴向透视、重复字墙、阶梯、唱片、雕塑叠层、声场、胶带、报刊、展讯、双色、书脊、便笺、包豪斯、花形、折页、十字、拉伸、沙漏、棋盘、斜切、叠印、套色、档案、轮廓、圆窗、双幕、百叶、断层、螺旋、吊牌、印刷。

海报作品允许使用强对比色。编辑器仍使用豌豆的中性白/黑表面、明确边框、小面积绿色状态。选择设计会更新作品配色，但不更改用户文字、尺寸或持续时间；用户可继续编辑颜色。为保留旧项目兼容性，原有 effect ID 保留，但映射到新海报构图。

工作台改为上方导出操作、大画布与播放条、底部横向设计库、右侧文字/节奏/画面/项目四组设置。移动端按画布、设计库、设置顺序排列。只显示当前设置组，原控件和事件保留。
