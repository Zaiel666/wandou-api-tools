# 豌豆AI工具 v1.0.90

本次为可靠性更新，保留现有界面与功能入口。

## 更新内容

- 修复对话助手的双渠道模型路由；切换项目、清空对话后，旧请求不再把结果写入新项目。
- PSD、SVG、AI、EPS 新生成的导出文件可在本机留存，重开项目后再次下载；新增完整性校验和缺失文件提示。
- PSD 分层增加十分钟总截止时间，完善取消、超时和重试清理。
- 音频任务固定发送时的参数，切换项目或删除节点会取消旧任务；超时后可重试。
- 区分新旧 TTS 声音选项，校验文字、格式和语速；识别空文件、HTML/JSON 错误和音频实际类型。
- 安装包不包含独立 UI 实验页面，保持正式页面不变。

## 使用说明与限制

- 更新前请保存项目，更新后确认版本号为 1.0.90。
- 导出文件留存在当前设备；项目 JSON 不携带导出文件二进制，跨设备前请另外下载文件。以前已经丢失的导出文件无法恢复。
- 本次不改变 PSD 拆层和矢量描摹算法，不承诺文字可编辑、语义分层或无损矢量重建。
- 尚未完成所有服务商的真实付费 API 验收；未验证的参考音频克隆接口不会发送猜测参数，上传与播放功能保留。

## 检查范围

本地逻辑回归包括对话渠道、任务隔离、导出留存、音频参数与超时；发布流程另检查更新器、安装包结构、启动与保存关闭。测试通过不等于所有第三方接口和所有使用场景没有问题。
