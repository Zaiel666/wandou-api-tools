# 豌豆 AI v2.0.0

新版首页和节点画布设为默认入口，继续使用原有项目和设置；首页保留旧版画布入口。独立测试页仍保留测试数据隔离。

## 本次内容

- 新首页与节点画布、统一工具页面样式。
- 动态文字海报、3D 导演台和桌面端 Blender 自动转换导入（需要本机安装 Blender）。
- 可拖动豌豆对话助手、循环表情动画。
- 滚轮事件按帧合并；缩放期间延迟媒体加载切换并分批处理。

## 本地验证（2026-10-16）

60 个非浏览器回归测试文件通过；包含更新器规则、存储恢复、保存退出、导演台转换、UI DOM、正式入口与缩放调度检查。
更新器正常覆盖与目录占用场景、便携包启动与保存退出检查通过。新增正式模式读取旧项目与测试数据隔离检查。

## 使用说明与验证边界

1. 更新前建议导出重要项目；旧版画布与新版正式画布共享项目数据，避免同时编辑同一项目。
2. 独立测试页项目不会自动合并到正式项目，可使用导出/导入项目功能迁移。
3. 没有安装 Blender 时会提示安装；不会静默下载或安装软件。
4. 未执行真实付费模型调用，未完成本地 file 页面浏览器帧率验证；大型画布性能仍需要用户实机反馈。升级测试使用隔离模拟安装目录，不是覆盖用户当前安装目录。

保留旧项目和 API 配置，不将缓存、用户数据、开发环境配置或调试截图上传到仓库。
