# 可靠性修复批次与功能保留清单

## 续批：音频参数兼容与响应识别

依据 OpenAI Docs 官方语音接口文档修正参数，保留现有节点布局：

- tts-1 / tts-1-hd 使用文档列出的 9 种声音，不再混用新版的 marin、cedar、ballad、verse；历史不合法声音设置归一为可用值。未知服务商的自定义声音名称不擅自改写。
- OpenAI Speech 的文本/声音指令长度、语速与输出格式在发请求前校验；不截断原文。Gemini 保持独立原生适配。
- 未知模型不再自动被判定支持参考音频。参考音频上传和播放保留；在取得该服务商的明确接口定义前，不发送猜测的 reference_audio/audio 字段。尚未实现参考音频克隆适配。
- 正确标记通用二进制响应的 MIME；识别 WAV/FLAC/Ogg/MP3 文件标记，结果扩展名跟随实际类型。
- 防止空文件、HTML 网关页面或 JSON 错误被误当成可播放音频；正常 JSON 音频地址继续支持。不再对正常整段二进制音频做无用的全文字符串解码。

新增 audio-api-compatibility.test.cjs 的 7 项模拟接口测试，连同此前累计 43 项通过。没有发起付费 API 请求，真实声音质量与服务商兼容性未验收。

资料：https://developers.openai.com/api/docs/guides/text-to-speech 、https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create

## 续批：音频任务生命周期

本批继续保持 UI 不变，新增 audio-task-lifecycle.test.cjs 的 5 项行为测试，连同前批共 36 项通过。画布脚本语法和 53 个发布文本文件的 UTF-8 检查通过。

- 音频请求快照保留发送时的提示词、模型、声音、格式、参考和渠道配置，避免等待期间的设置变化影响结果记录。
- 切换/导入/新建项目、重置画布、删除音频节点或对应结果节点会取消旧音频任务；迟到结果不进入新项目，也不触发新项目保存。
- 五分钟超时通过可取消等待立即结束本地任务，即使底层传输未响应取消；清理定时器和生成状态，允许再次生成。
- 空音频文件和没有音频地址的结果显示失败，不再作为可播放成功结果。
- 重开项目时解除历史 audioGenerating 状态，提示上次生成已中断。
- 本批未增加新的手动取消按钮，未改变声音/格式设置界面，未调用付费 API。音频服务商能力表、参考音频兼容性和真实播放验收仍待完成。

## 已完成的修改

1. 对话按模型所属渠道选择地址和密钥，传给接口的模型 ID 不包含“渠道 2”显示后缀。渠道 2 可独立使用；未配置密钥时保留草稿并定位对应输入框。
2. 自动选择仅从可用渠道的文字模型候选中选取，保留同渠道自动重试；遇到权限/余额错误停止重试。名称过滤只排除已知不适用的模型，不等于完整的服务商能力验证。
3. 每条对话请求绑定原项目与原对话。切换、新建、导入、删除项目，重置画布或清空对话时取消旧任务，迟到回复不得写入新项目。旧任务结束不会解锁新任务的发送状态。
4. 请求超时即使遇到不响应取消的传输也能结束本地等待。错误和取消提示不会作为助手回答再次发给模型，刷新后保留这些状态标识。
5. PSD、SVG、AI、EPS 的导出文件可持久留存：新版桌面桥接使用应用数据目录下的 export-artifacts 二进制文件；浏览器使用独立 IndexedDB。项目数据只保存索引，不嵌入大型文件内容。
6. 文件使用 SHA-256 标识并校验，加载时检查原图与生成参数；同 ID 的其他项目节点不能复用旧缓存。磁盘写入失败仍保留本次内存下载，并显示需立即下载的提示。
7. 下载采用按需加载，打开项目时不一次性读取全部大型 PSD。缺失文件、损坏文件、源图变化都有明确错误说明。
8. PSD 任务增加共用的 600 秒总截止计时，保留原有阶段超时；取消/失败时清理任务状态和计时器。此截止作用于异步任务，渲染线程上的同步编码仍不能被计时器抢占。
9. 矢量生成加入项目和任务标识检查，切换项目、删除节点或改变源图后，旧任务不得写入新节点。

## 限制与下一批工作

- 没有连接真实付费 API；没有完成当前本地页面和 Electron 客户端点选验收，不能宣称全程序已无 bug。
- 桌面磁盘留存依赖新主进程/预加载桥接。旧安装版打开新页面时可能退回浏览器存储；需要后续打包才能让安装版使用新桥接。
- 已丢失的历史内存文件无法恢复。新生成文件开始留存；原有已下载文件不受影响。
- 文件索引随项目保存，但导出项目 JSON 不包含二进制文件。跨设备导入需要在原设备下载产物，不能把索引当作文件已搬迁。
- “本地”不等于无限容量：磁盘/浏览器配额仍适用。存储失败会提示，不假装保存成功。
- 导出文件按内容保存，删除节点不自动删除磁盘文件，以便撤销、旧项目与备份仍能找回；暂未提供专门的导出文件清理入口。
- 取消会停止本地等待并尽可能通知接口；远端是否停止计算和计费取决于服务商。
- PSD 智能蒙版质量、可编辑文字、语义矢量重建、音频能力表、真实 API 兼容性仍待专项修改。
- 后续继续完善其他生成任务的生命周期与绘图、音频、参考图区域的真实黑白蓝 UI 样板；这些尚未完成，v1.0.90 仅发布本批可靠性修复。
