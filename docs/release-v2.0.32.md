# v2.0.32 更新说明

本次主要修复安全更新的错误提示与下载地址校验，不修改项目格式和数据目录，也不重新生成用户图片。

## 下载及安装

从 [本版发布页](https://github.com/Zaiel666/wandou-api-tools/releases/tag/v2.0.32) 下载安装器。已有用户先保存退出，运行安装器并选择原程序目录。保留原图、项目、自建文件和数据目录设置；安装器遇到未知文件冲突会停止。

本候选以手动安装包发布，make_latest:false，旧 Latest 保持 v2.0.16。发布时 desktop-safe-v1 保持关闭；先完成候选包匿名下载、安装及自动重开验证，再按独立验收计划开放通道并验证完整发现链。未通过不宣称自动更新可用。v2.0.22 及更早版本不要使用旧在线更新器，应使用本版 setup。

## 已修复

- 当通道直连和备用请求出现混合网络错误时，保留可重试状态。
- 区分通道确实不存在、发布存在但附件读取失败，以及发布元数据损坏。
- 更新包和校验文件只接受指定仓库、版本与文件名的规范地址，不接受查询串、片段或模糊路径别名。
- 正常 GitHub 资源 CDN 的安全重定向仍受支持。

## 保留的限制

公网安全更新完整链尚待独立验证，不以手动 setup 成功代替。安装包尚无发行者代码签名。旧损坏工作台数据库缺少关键文件时不能保证恢复；保守回退也可能拒绝不兼容或损坏数据库。

模型高分辨率与本地放大分别标记，SVG/GIF 取决于所选渠道支持；分层 PSD 为本地处理，不代表官方 API 原生输出分层 PSD。全部渠道、全部真实项目、多硬件及多日运行未全面验证。会员、积分、云同步和商店发行继续暂缓。

详见 [测试范围](verification-v2.0.32.md)。
