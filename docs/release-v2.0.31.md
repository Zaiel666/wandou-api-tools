# 豌豆 AI v2.0.31

本版改善宽屏首页、分类和资产布局，并修复保存关闭、草稿落盘与导出期间退出的可靠性问题。保留 v2.0.30 的画布启动、项目恢复、原图保存和配置同步修复。

## 下载与升级

- [Windows x64 安装包（推荐）](https://github.com/Zaiel666/wandou-api-tools/releases/download/v2.0.31/wandou-ai-tools-setup-2.0.31.exe)
- [Windows x64 便携版 ZIP](https://github.com/Zaiel666/wandou-api-tools/releases/download/v2.0.31/wandou-ai-tools-windows-x64.zip)

请先保存并正常退出软件，再运行安装包，选择原软件目录。重要项目建议保留独立备份。安装器校验程序清单并保留项目数据、自建文件和旧程序备份；遇到冲突或不能识别的旧版会停止覆盖，不要删除项目文件绕过提示。已有独立数据目录继续使用原设置。新安装可选择空间充足、当前用户可写的目录。

本次为**手动安装发布**，不设为旧客户端自动更新的 Latest，也不启用固定安全更新通道。v2.0.16 的旧内置更新器存在删除软件目录自建文件的已知问题，请使用本页安装包。便携 ZIP 请解压到独立目录；页面的 Source code 是开发源码，不是 Windows 安装包。

安装包目前没有 Windows 发行者数字签名，系统可能显示信誉提示。请核对官方发布地址与随附 SHA256，不需要关闭安全保护。升级后有新数据时，不要仅替换旧 EXE 降级；不兼容或损坏历史库可能无法安全回退。

## 修改内容

- 首页、分类及资产共用内容区随窗口宽度展开；宽屏常用工具采用横向图文卡片，图片、提示词及音视频分类更清晰，保留原入口和明暗主题。
- 正常点击关闭时先保存，收到成功结果才退出；修复无回应、保存异常、迟到回执及重复关闭导致的卡住或误退出。
- 保存失败或页面无响应时提供明确的等待、重试或退出选择；需要放弃未保存内容时由用户确认，不静默丢弃。
- 退出前等待网格海报草稿提交。外部网页无法确认保存状态时明确提示，不把本地保存成功当作外站已保存。
- 下载图片、PSD导出、动态海报准备/编码和生成准备期间增加关闭保护；取消下载不会报告为保存成功。更新、迁移等关键写入继续受保护。

发布前另用最终安装器的实际安装核心，从公开v2.0.16、v2.0.22完整包在全新临时目录直接升级，逐文件核对新程序、旧程序备份及中文路径合成数据、自建文件。此专项不替代所有旧历史数据或安装向导界面的验证。
