# v2.0.33 更新说明

本版改进更新下载、兼容画布原图导出、安装目录说明和界面层级。已有用户应先保存并退出，再使用安装器选择原程序目录进行手动升级；用户选择过的独立数据目录继续沿用。

- 更新下载器对受信任的 GitHub 重定向进行校验和跟随。自动更新公网发现、下载、安装、重启的完整链尚未验收，安全更新通道仍关闭。
- 新旧画布下载时按实际原图内容选择格式；处理旧 SVG 类型记录和本地处理后图片的导出来源。
- 旧画布遇到未支持的原生 SVG/GIF 生成或标注入口时提示切换到当前画布；不将该提示表述为旧画布已经具备对应能力。
- 安装器说明强调可选择有足够空间的目录，保留用户已有数据目录选择；修正助手入口的遮挡层级。

模型原生尺寸与本地放大分别标记。SVG/GIF 效果和输出参数取决于服务渠道；PSD 为本地分层处理，不代表官方 API 原生生成分层 PSD。安装器未做发行者代码签名。旧工作台数据库若已损坏且缺少关键文件，不能保证恢复。

具体已验证范围和已知限制见 [测试范围](verification-v2.0.33.md)。
