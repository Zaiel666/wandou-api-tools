# 豌豆AI工具 v1.0.91

## 更新内容

- 修复参考图批注新增、修改或删除后，已连接的 AI 绘图节点未实时更新批注列表的问题。
- 统一节点和侧边控件的黑白灰配色，修正白天模式下仍显示深色背景的区域。
- 完善参考图拖入、批注及画笔相关交互；保留原图与已保存的编辑数据。
- PSD 分层采用先分析、检查图层，再确认生成的流程，减少误拆层；导出前仍需人工检查结果。

## 更新与使用说明

- 更新前请保存项目。更新后在软件中确认版本号为 1.0.91。
- 本次不保证第三方模型一定能准确拆出文字和图形，也不把位图自动变成真正可编辑的矢量路径。
- 批注仅在参考图与绘图节点保持连接时参与当前生成；删除批注后，不会再加入后续生成提示词。
