# 豌豆AI工具 v1.0.86

本版本集中修复大画布保存、PSD 分层、音频生成与节点交互，并新增矢量文件导出。

## 更新内容

- 画布、项目与 API 配置优先保存到本机磁盘和 IndexedDB，不再受浏览器 `localStorage` 容量上限影响。
- 自动迁移旧版画布数据；只有持久化写入成功后才用轻量指针替换旧缓存。
- 新增 SVG / Adobe Illustrator AI 节点，支持保真嵌入和可编辑描摹两种导出模式。
- PSD 分层改用可用的高版本 GPT 视觉模型进行语义分析，并把单次分析等待时间延长到十分钟以内。
- 改进 PSD 图层语义合并、文字/背景/主体识别和下载按钮尺寸。
- 修复 Gemini 原生 TTS 与 OpenAI Speech 路由、语音格式、重试和 WAV 封装。
- 重做 AI 音频节点：默认紧凑显示，点击后展开详情，点击画布空白处自动收起。
- 新增音频关键词、模型选择器和统一的“音频设置”弹出层；声音、格式、语速与声音指令可直接选择。
- 上传音频可在节点中播放；文字型 TTS 不会错误提交不支持的参考音频。
- 移除音频详情底部的技术说明文字，并统一深色主题、间距、图标、按钮和选中状态。
- 放大结果与文件下载按钮，补充保存、恢复、API 配置和导出回归测试。

## 验证

- 桌面端 JavaScript 语法检查。
- 全量自动化回归测试（真实付费 API 测试除外）。
- 音频节点上传、播放、关键词、设置弹出层、Gemini TTS 与 OpenAI Speech 浏览器测试。
- PSD、SVG、Adobe AI、项目恢复、本地磁盘保存和缓存迁移测试。
