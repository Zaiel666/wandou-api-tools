# 豌豆AI工具 v1.0.89

本版本集中修复节点画布中的参考图、PSD/SVG 文件生成和遮罩绘制反馈问题。

## 更新内容

- 修复对话模式上传图片后，参考图未在消息区域正常展示的问题。
- 为参考图添加 1–6 序号，并在提交给模型时保留相同编号，方便准确引用图片。
- 参考图消息改用本地媒体存储，刷新或重新打开项目后仍可恢复显示。
- 修复 PSD 节点点击“生成拆分”没有反应的问题，并补充处理中状态和明确错误提示。
- 修复 SVG/矢量文件节点没有反应的问题，完善本地媒体解析、SVG 文件识别及失败反馈。
- 参考图遮罩编辑新增圆形画笔尺寸预览，光标会跟随实际画笔大小变化。
- 橡皮擦新增虚线圆形尺寸预览，便于确认擦除范围。

## 验证

- UI V3 回归检查 16 项全部通过。
- 对话参考图显示、编号与请求内容回归测试通过。
- PSD 与 SVG/矢量节点点击响应和错误反馈测试通过。
- 参考图画笔、橡皮擦浏览器交互测试通过。
- Git 差异与发布文件格式检查通过。
