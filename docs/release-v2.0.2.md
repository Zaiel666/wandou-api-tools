# v2.0.2 对话浮窗与保存保护

- 对话模式改为覆盖画布的独立浮窗，不再预留右侧空白，底部工具栏不随浮窗移动。
- 保留对话面板拖动、八方向缩放及位置记忆。
- 画布未初始化或页面结构缺失时，关闭前保存明确返回失败，不写入空项目，不再触发 classList 空引用错误。
- 保留 v2.0.1 的桌面画布启动修复与旧项目数据兼容。

发布检查：49 项入口、存储、保存与 DOM 测试；4 项保存和更新回归脚本；真实更新器的正常及目录锁定路径；最终便携包启动检查。所有更新测试使用隔离临时数据。

检查不覆盖所有远程生成接口，也不等同于完整桌面视觉验收。保存失败仍会阻止退出和更新，避免丢失项目。
