# v2.0.3 创作界面与动态海报升级

- 节点画布：统一创建菜单、图片菜单的图标及悬停效果，修复提示词库明暗主题，优化结果图圆角与悬停信息。
- 图片预览菜单新增下载图片，保留复制、关键词查看及重新生成。
- 对话助手：四个创意入口、渐变输入框、新对话自动归档、按项目查看及恢复历史。归档失败保留当前对话，回复期间禁止切换。
- 动态海报：新增几何文字模板、字体与本机字体选择、动画速率控制、透明 PNG/APNG 导出，修复进度条和数值显示。
- 保留桌面画布初始化、旧项目存储兼容和关闭前保存保护。

## 发布验证

- 110 个非付费接口回归测试文件运行通过（部分测试按环境自带跳过条件）。覆盖入口、项目存储、保存、生成请求组装、导出、主题和交互。
- 独立编译更新器：正常更新和安装目录锁定回退均通过，验证迁移、重启及清理。
- v2.0.3 便携包使用隔离用户目录通过启动、保存和正常退出检查。
- 发布附件提供 SHA-256 校验文件和更新清单。

未调用真实付费生成接口；测试不能保证所有第三方模型服务可用。对话助手支持创建提示词节点和接收图片结果，尚不支持自动执行整套节点工作流。

升级不会主动清理用户项目。建议升级前保留项目导出备份；历史记录按当前项目存储在本机。
