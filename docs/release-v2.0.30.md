# 豌豆 AI v2.0.30

本版集中修复画布打开、保存、项目恢复和配置同步，包含 v2.0.23 至 v2.0.30 的本地改进。建议使用 **Windows x64 安装包** 更新。

## 下载与安装

- [下载安装包 wandou-ai-tools-setup-2.0.30.exe](https://github.com/Zaiel666/wandou-api-tools/releases/download/v2.0.30/wandou-ai-tools-setup-2.0.30.exe)
- [下载便携版 ZIP](https://github.com/Zaiel666/wandou-api-tools/releases/download/v2.0.30/wandou-ai-tools-windows-x64.zip)
- 页面下方的 Source code 是开发源码，不是 Windows 安装包。

更新前保存并正常退出软件，备份重要项目，再运行安装包并选择原软件目录。新安装可选择空间充足、当前用户可写的目录；已设置的独立项目数据目录继续保留。安装器会校验受管程序文件，保留数据、自建文件及旧程序备份；遇到文件冲突或无法识别的旧程序时会停止覆盖，请保留现场，不要手动删除数据来绕过检查。

**本次只提供手动安装更新，不设置为旧客户端自动更新的 Latest。** v2.0.16 的旧内置更新器存在删除程序目录自建文件的已知问题，请使用本页安装包。固定安全更新通道的公网全链验收尚未完成，本次发布不会开启该通道。便携版适合解压到新的独立目录，不建议直接用资源管理器覆盖混有项目数据的旧目录。

安装包尚未取得 Windows 发行者数字签名，可能出现系统信誉提示。请核对下载来源及随附 SHA256；不要为安装关闭系统安全保护。安装后已产生新数据的用户不要只替换旧 EXE 来降级，损坏或不兼容的历史库可能无法安全回退。

## 主要改进

- **画布打开与恢复**：本地项目不再等待可选的在线配置、模型和技能服务；按当前项目读取必要快照，避免打开时遍历全部历史正文；修复旧启动指针遮住有效项目、错误切换项目及读取失败后空内容覆盖的风险。
- **保存与大画布操作**：减少同一媒体的重复持久化及保存后逐节点重复刷新；保留视口裁剪、低缩放简化预览、长节点适应画布及助手避让。失败、关闭、重开及并发写入增加保护。
- **图片与资产**：原图与预览分开管理，支持原文件位置、打开文件夹和自选位置另存为；按真实格式生成可直接查看的标准原图副本，兼容旧 `.data`。原件缺失时明确反馈，不用预览冒充原件。
- **数据目录**：工作台浏览器作品和项目数据跟随所选数据目录，迁移失败不会静默创建空库。部分主配置、系统缓存和旧兼容副本仍可能保留在 Windows 用户目录；本版不会自动清理它们。
- **配置与生成任务**：修复跨页面配置草稿、保存确认、未编辑渠道保留及旧值写回；配置尚未就绪、草稿未保存或保存中时阻止提交，不自动排队或重新发起付费生成。有限协议支持手动查询已提交任务，不承诺所有渠道的崩溃续查。
- **首页与主题**：统一明暗主题、导航和教程弹窗行为；首页轮播箭头居中，移除暂停按钮，并修复交互后自动轮播停止的问题。
- **SVG/GIF**：保留侧栏快捷入口、原件下载与实际参数差异提示；支持明确标注的本地尺寸或时长调整副本。渠道返回的实际尺寸、帧数、时长仍可能与请求不同。
- **安装与更新保护**：按清单更新受管程序，保留额外自建文件；增加保存交接、哈希校验、冲突检查及失败回滚保护。

## 验证范围

冻结版本已通过 85 个测试文件的 **990/990** 检查，以及原图专项、真实系统另存为取消/自选路径、最终包启动保存关闭、实际覆盖升级、安装后原生检查和快捷方式重开。最终包、从 v2.0.28 升级后的程序及实际安装程序分别完成 60 项原生检查。发布时沿用哈希完全相同制品的验收记录，不把它们称为本轮重新执行。

发布前另外使用最终安装包的实际安装核心，在独立临时目录分别从公开 v2.0.16、v2.0.22 完整旧包直接升级到 v2.0.30；两条路径均核对 318 个新程序文件、完整旧程序备份及合成数据、自建文件 SHA。该专项测试的是安装核心与文件保留，不是所有历史数据或安装向导界面的全面验证。

固定合成素材完成约 30 分钟画布操作、保存和重开循环，以及五档缩放检查。这只代表测试机器与固定素材的结果，不是所有项目、所有硬件、FPS 或无内存泄漏的保证。

## 仍有的限制

- 已损坏、缺少数据库元信息的旧工作台历史不能保证恢复；本版不会伪造历史数量或以预览代替丢失的原图。
- 公网自动更新完整链路、发行者签名、官方原生分层 PSD、所有渠道和全部真实旧项目、多硬件长期运行尚未全部完成验证。现有本地 PSD 导出不等于官方模型直接生成分层 PSD。
- 上游接口是否遵循尺寸、帧数等参数取决于渠道；本地放大和格式调整会注明非原生处理。
- 会员、积分、云同步和商店发行继续暂缓。该版本不包含自动清理真实项目或旧备份。
