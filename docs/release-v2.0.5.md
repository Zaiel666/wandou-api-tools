# v2.0.5 画布响应与便携更新修复

- 节点画布复用未变化节点的界面，限制画布外节点的动效，清理替换节点的观察器；切换桌面标签页时合并保存请求并在返回后恢复显示，减少卡顿。
- 修复便携版软件内更新后可能残留的 `wandou-ai-stage-…` 文件夹。更新器会重试清理；软件启动后也会安全清理已完成或过期的暂存目录。
- 移除首页旧版画布入口，修正项目侧栏“新建项目”按钮宽度，并使资产页和网格海报的返回入口指向当前画布。
- 废弃的首页设计预览不再进入安装包；正式画布版本标识与提示更新为 v2.0.5。

## 发布验证

- 118 个非付费接口回归测试文件通过；主要六个页面的本地打开检查无空白页或脚本报错。
- 便携更新器的正常更新、安装目录锁定回退及暂存目录清理检查通过。
- 桌面应用重新打包后通过独立用户数据启动与正常退出检查；发布附件包含 ZIP、SHA-256 校验文件和更新清单。
