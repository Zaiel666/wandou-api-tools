# GRIDFORM 组件规格

## 设计变量

| 变量 | 值 |
| --- | --- |
| 页面背景 | `#090a09` |
| 工作区 | `#111210` |
| 浮层/控件 | `#171816` |
| 分隔线 | `#30322e` |
| 主文字 | `#f2f2ec` |
| 次文字 | `#8d8f89` |
| 强调色（原站） | `#eaff00` |
| 豌豆 AI 本地强调色 | `#2f86ff` |
| 蓝色强调上的文字 | `#ffffff` |

## 几何与状态

- 控件圆角以 4–6px 为主，弹窗为 9px；不使用大面积胶囊按钮。
- 主按钮使用豌豆 AI 蓝色，普通按钮和面板保持黑灰层级。
- 选中构图以蓝色边框和右上角勾选标记表示。
- 画布选中元素、四角控制点与吸附参考线统一使用蓝色层级。
- 左侧页签用 2px 强调色底线，不额外增加卡片容器。
- 画布背景为 12px 间距的细点阵，海报使用低位阴影悬浮。

## 本地集成差异

视觉与编辑行为保持一致。品牌区替换为项目现有的豌豆 AI 原版 Logo，交互强调色统一为 `#2f86ff`。此外，把原站“返回 AI 资产平台”替换为“返回 AI 节点画布”，并把扣积分导出替换为本地免费导出，以避免误导和无效服务端调用。
