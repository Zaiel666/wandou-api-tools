# GRIDFORM 页面拓扑

来源：`https://www.aixc4d.com/gridform`（2026-09-20 只读采集）

## 桌面结构

1. 平台栏，36px：返回入口、编辑/导出说明。
2. 顶部栏，70px：品牌 Logo、工作台名称、保存状态、撤销/重做、保存、导出格式和主导出按钮。
3. 主工作区：左侧 300px 设计面板，右侧弹性工作室。
4. 设计面板：文案、素材、网格、画布四个页签；内部独立滚动，底部固定操作提示。
5. 工作室工具栏，52px：当前构图与画布尺寸、位置和网格操作。
6. 画布视口：深色点阵背景、居中的海报画板、画板标签、缩放控制。
7. 构图坞：18 个横向滚动构图卡、保留手动位置、变体与随机生成。

## 响应式结构

- 1100px 以下：左侧面板收窄到 270px，隐藏低优先级说明。
- 700px 以下：工作室在上、设计面板在下；工作室固定高度，顶部和构图操作换行。

## 本地页面映射

- 页面：`app/gridform.html`
- 原始公开样式：`app/gridform.css`
- 本地主题补充：`app/gridform.local.css`
- 原始公开画布/构图引擎：`app/gridform.vendor.js`
- 本地导出与导航适配：`app/gridform.local.js`
- 节点画布入口：`app/ai-node-canvas.html#openGridformButton`
