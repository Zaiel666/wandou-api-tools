# 豌豆AI工具 v1.0.87

本版本新增豌豆 AI 网格海报工作台，并进一步修复 PSD 分层与矢量文件可编辑性。

## 更新内容

- 在节点画布侧栏新增“网格海报工作台”入口，可随时进入独立海报编辑页面。
- 新增 18 套网格构图，支持文案、图片、透明 Logo、网格、画布比例与配色调整。
- 支持画布元素选择、拖动、缩放、吸附、双击编辑、撤销重做和随机变体。
- 海报草稿保存在本机，支持本地导出 2 倍分辨率 PNG 和分层 PSD，不依赖积分接口。
- 工作台替换为豌豆 AI Logo，并把按钮、页签、选中框和控制点统一为豌豆蓝视觉。
- PSD 拆层增加图层像素互斥处理，降低文字、主体与元素层重复覆盖的问题。
- PSD 分析提示强化文字、背景、主体、装饰与界面元素的语义区分。
- SVG、Adobe Illustrator AI 与 EPS 默认生成真实路径对象，不再默认嵌入原始位图。
- SVG 与 AI 支持颜色图层和独立对象，EPS 支持标准可编辑路径输出。

## 验证

- 网格工作台 18 套构图、四个编辑面板和入口跳转测试。
- PNG 下载文件签名与 PSD 文件头、文件大小、分层数量验证。
- PSD 图层像素互斥回归测试。
- SVG、Adobe AI、EPS 可编辑路径和分层导出测试。
- 原节点画布深色主题与现有 PSD 导出回归测试。
