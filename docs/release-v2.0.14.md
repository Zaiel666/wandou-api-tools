# 豌豆 AI v2.0.14

2026-10-25 · Windows x64

本次更新支持选择独立的项目数据目录，并修复保存、图片恢复及画布交互中的已确认问题。

## 项目数据目录

在首页设置中打开“项目存储 → 存储设置”，或在资产页点击“存储设置”。选择一个磁盘或父文件夹，软件会使用其中的“豌豆AI数据”目录。选择后先显示完整路径和容量；点击“保存并重启以迁移”才开始保存和迁移。

迁移包含原图、画布备份、项目本地数据及项目索引。软件会先保存打开的画布，重启后复制数据，逐文件校验 SHA-256，并确认源文件没有变化，最后切换保存位置。迁移失败时保持原目录；成功后也保留旧副本，供确认数据完整后处理。旧副本在删除前仍占用原磁盘空间。

旧版默认位置是 `%APPDATA%\豌豆AI`。更改项目目录后，API 配置、账户信息和 Chromium 浏览器存储仍保留在原位置。工作台浏览器中的记录不属于本次文件目录迁移范围。软件更新不会移动所选的独立数据目录；请勿选择程序安装文件夹。所选磁盘不可用时软件会提示连接磁盘并重试，不会自动切换到空白项目库。

## 图片和画布

- 资产 → 所有图片 → 图片卡片的“原文件位置”，可查看并打开实际存储位置。
- 图片保存在软件管理的媒体库中；只有主动下载时才导出图片。内部 `.data` 文件包含原图数据，不是改名后的 PNG。
- 修复全部删除节点后重新打开画布恢复旧节点的问题；撤销和重做保留正确的空画布状态。
- 包含此前本地版本的保存恢复、图片预览、画布交互、模型尺寸选项和明暗主题同步修复。

## 升级

先保存项目并完全退出旧版，再完整解压 Windows 包。保留已有项目数据，不要将旧版本和新版本混放。源码版本、包内版本及发布标签均为 v2.0.14。

此版本经过隔离数据和桌面运行验证。模型接口测试使用模拟响应，没有调用收费生成接口；不同服务商的实际尺寸支持及超大项目性能仍受接口和设备条件影响。
