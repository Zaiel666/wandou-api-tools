# 豌豆AI工具 v1.0.81

- 重做 AI 绘图提示词编辑器，将参考图、提示词输入和三项常用工具整合到同一紧凑面板。
- 随程序内置 1742 条开源提示词，支持来源、标签和标题搜索；联网时自动刷新本机缓存，断网首次打开仍能使用完整词库。
- 修复提示词库无法使用鼠标滚轮继续浏览的问题，支持滚动隔离、触控纵向滚动和卡片增量加载。
- 移除参考图区“参考内容 / 已连接”标题，缩略图直接置顶；三个提示词工具按钮统一为白色圆形描边。
- 统一画布右上角工具栏的尺寸、间距与深色视觉，并保留左键双击菜单和禁用右键菜单行为。
- 强化跨屏幕环境的节点拖动回归测试，避免云端测试因固定坐标产生误报。

下载 `wandou-ai-tools-windows-x64.zip`，解压后运行 `豌豆AI工具.exe`。覆盖旧版前请先关闭程序；用户数据保留在原位置。
