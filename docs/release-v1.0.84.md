# 豌豆AI工具 v1.0.84

- 新增两套独立 API 渠道。渠道 1 为必填默认渠道，渠道 2 选填；同名模型会以“渠道 2”标识区分，并使用对应密钥请求。
- 修复 API 密钥眼睛按钮无响应的问题，首页和节点画布均可可靠显示、隐藏两组密钥，关闭设置后自动恢复隐藏。
- 新增 AI 音频节点，默认使用 `gemini-3.1-flash-tts-preview`，支持文本生成、声音/格式/语速设置、参考音频上传、播放和下载。
- 改进 PSD 智能分层，按完整主体、文字块、装饰元素组和光效系统等语义对象组织图层，减少零碎图层。
- 修复扩图画面出现分块和接缝的问题，并继续保留可视化扩图画布、比例调整与原图保护。
- 保留可滚动提示词库、左键双击节点菜单、禁用右键菜单以及统一放大的画布顶部工具栏。

下载 `wandou-ai-tools-windows-x64.zip`，解压后运行 `豌豆AI工具.exe`。覆盖旧版前请先关闭程序；用户数据保留在原位置。
