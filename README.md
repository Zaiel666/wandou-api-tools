# 豌豆 AI 工具

Windows x64 桌面 AI 创作工作台，提供节点画布、图片生成、图片编辑、素材管理和提示词工具。

## 下载与安装

从 [v2.0.22 发布页](https://github.com/Zaiel666/wandou-api-tools/releases/tag/v2.0.22) 下载安装：

- 新用户：运行 `wandou-ai-tools-setup-2.0.22.exe`，选择空间充足、有写入权限的目录。
- 便携使用：下载 `wandou-ai-tools-windows-x64.zip`，解压后运行 `豌豆AI工具.exe`。
- 更新现有软件：先保存并退出软件，再使用新安装器选择原程序目录。完整保留“豌豆AI数据”和已选择的独立数据目录。

**v2.0.16 用户请使用安装器手动更新，不使用旧版“立即更新”。** 实测旧更新器会删除用户另放在程序根目录中的自建文件，虽然“豌豆AI数据”内项目和原图得以保留。新包无法提前替换负责这一次更新的旧更新器。因此本次发布没有设置为 GitHub Latest，也暂不作为软件内自动更新推送。

首次使用在设置中填写自己的 API 配置。调用由所选服务商计费，安装包不包含共享密钥。节点项目、原图及备份默认位于程序目录中的“豌豆AI数据”，也可选择独立数据目录；已有自定义目录继续使用原选择。浏览器版数据与桌面版分开，API 设置等部分用户配置仍由桌面用户配置目录保存。

## v2.0.22

- 侧栏增加“SVG 矢量”“GIF 动图”，复用现有生成、保存及原件下载流程。
- 保留“矢量转换”，用于将已有图片在本地转换为 SVG / AI / EPS。
- 支持圈画编辑、质量与复杂度选择，原图与标注分开保留。
- 完善任务取消、项目归属、关闭保存及大画布的预览加载。
- 修复创建菜单超出窗口，以及模型目录缺项时错误替换当前兼容模型。

具体功能取决于模型和渠道权限。本轮真实渠道测试能返回有效 SVG/GIF，但没有完全遵循 SVG 画布尺寸和 GIF 帧时长；不能把所有选项都视为已通过所有渠道验证。PSD 功能是本地分层处理，不代表官方 API 原生输出分层 PSD。

详见 [更新说明](docs/release-v2.0.22.md)、[测试范围](docs/verification-v2.0.22.md) 和 [源码构建](docs/BUILD.md)。

## 发布与校验

更新器下载固定名称的 ZIP，并核对 SHA-256。每个版本同时提供安装器、ZIP、各自校验文件和 `update-manifest.json`。发布使用经过本地验收的制品；标签不会触发重建或覆盖附件，手动工作流只验证已发布文件。

源码标签与对应安装包一起发布。安装包尚未提供发行者代码签名；本项目不承诺所有硬件、渠道及未知故障均已覆盖。
