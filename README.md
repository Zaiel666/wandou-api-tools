# 豌豆 AI 工具

Windows x64 桌面 AI 创作工作台，提供节点画布、图片生成与编辑、素材管理和提示词工具。

## 下载与安装

从 [v2.0.30 发布页](https://github.com/Zaiel666/wandou-api-tools/releases/tag/v2.0.30) 下载。

- 推荐安装器：wandou-ai-tools-setup-2.0.30.exe，选择空间充足、有写入权限的目录。
- 更新已有软件：先保存并退出，再运行安装器并选择原程序目录。保留项目、自建文件和独立数据目录；遇到未识别的程序文件冲突会停止。
- 便携使用：新建目录解压 wandou-ai-tools-windows-x64.zip，运行豌豆AI工具.exe。旧版升级优先使用安装器，避免手动混合覆盖新旧运行文件。

**v2.0.22 及更早版本请使用安装器手动更新，不使用旧在线更新器。** 旧 v2.0.16 更新器曾验证会删除程序目录的自建文件。本次没有设置 GitHub Latest，也不开放 desktop-safe-v1 固定更新通道，不向旧客户端推送更新。

首次使用在设置中填写自己的 API 配置，调用由所选服务商计费，安装包不含共享密钥。项目、原图、API 设置的磁盘副本和工作台浏览器存储跟随所选数据目录；默认位于程序目录内的“豌豆AI数据”，已有自定义目录继续使用原选择。少量主配置、GPU 缓存和旧版兼容副本可能仍在 Windows 用户配置目录。存储设置可查看实际位置。

下载图片时可自行选择位置。资产页可查看原件位置并打开所在文件夹。浏览器版使用独立浏览器存储，与桌面版项目分开。

## v2.0.30

- 本地画布恢复不再等待可选 API、模型目录和技能加载；减少启动时全量读取快照。
- 修复旧占位项目遮住有效当前项目、错误切换其他项目；读取失败时保护原件并提供重试。
- 修复 API 草稿、跨页面配置保存和保存中提交；配置未就绪时阻止生成，不自动补发收费请求。
- 改善大画布保存、缩放预览与适应画布，减少重复媒体处理及刷新。
- 改善标准原图存储、资产文件夹定位、下载、工作台会话迁移与备份检查。
- 修复首页轮播箭头居中、自动轮播、导航、主题和教程弹窗。
- 安装/更新按受管文件清单替换程序，保护自建文件，保留事务备份。

模型原生尺寸与本地放大分别标记；渠道可能不遵从 SVG 尺寸、GIF 帧时长等请求参数。PSD 是本地分层处理，不代表官方 API 原生输出分层 PSD。既有损坏数据库不能保证自动恢复。

## 发布与校验

每版提供安装器、ZIP、各自 SHA-256 校验文件及版本清单。源码标签与对应包一起发布。标签不会触发重新构建或覆盖附件。版本内的 update-manifest.json 用于描述与校验，不代表安全自动更新通道已上线。

安装器尚无发行者代码签名，Windows 可能显示未知发布者提示。请从上述仓库下载并对照 SHA-256；无需为安装关闭系统安全功能。全部渠道、真实项目、多硬件和多日使用尚未覆盖，不承诺没有未知故障。
